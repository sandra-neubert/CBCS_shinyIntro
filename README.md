# Introduction to R Shiny

R Shiny workshop for the CBCS Coding Club (02/05/2025).

All the scripts contain a shiny app that can be run by just running the whole script. The [wdpar](https://cran.r-project.org/web/packages/wdpar/vignettes/wdpar.html) script (`shinydashboard_wdpar.R`) might take a bit longer to run due to processing times of the protected area data. 
<br>
Here are some useful links for working with shiny:
<br>
* [Shiny Basics on Posit](https://shiny.posit.co/r/getstarted/shiny-basics/lesson1/)
* [Mastering Shiny by Hadley Wickham](https://mastering-shiny.org/index.html)
* [Outstanding User Interfaces with Shiny by David Granjon](https://unleash-shiny.rinterface.com/)
* [Engineering Production-Grade Shiny Apps by Colin Fay et al.](https://engineering-shiny.org/)
* [Building Shiny Appy by Dean Attali](https://deanattali.com/blog/building-shiny-apps-tutorial/)
